
# Professional Resume Card

A modern, responsive personal resume card built using HTML, CSS, and JavaScript. This project presents my academic background, technical skills, projects, and professional interests in a clean and organized layout.

## Live Demo

[View Live Resume](https://minahil-cs.github.io/professional-resume-card/)

## Features

- Responsive design for desktop, tablet, and mobile screens
- Professional navy-blue interface
- Education and academic background
- Technical skills and areas of interest
- Experience and training section
- Featured projects with repository links
- Contact information and social profiles
- Print-friendly layout with PDF export
- Smooth navigation and subtle animations

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Minahil-CS/professional-resume-card.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation are required.

## Customization

Update the HTML file with your personal details, education, experience, skills, and project links.

Modify `style.css` to customize the colors, typography, layout, and responsive behavior.

Use `script.js` to modify the interactive features.
